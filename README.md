# Grêmio - Landing Page

## Sobre o projeto

Este projeto é uma Landing Page desenvolvida para apresentar informações
sobre o Grêmio Foot-Ball Porto Alegrense, incluindo sua história,
jogadores, títulos e estádio.

O projeto foi desenvolvido como atividade prática da Unidade Curricular
de Versionamento e Colaboração do SENAI.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.

## Estrutura do projeto

- `index.html` — estrutura principal da página.
- `style.css` — estilos da página.
- `script.js` — funcionalidades em JavaScript.
- `.gitignore` — arquivos que não devem ser enviados ao Git.
- `README.md` — documentação do projeto.
